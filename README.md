# prog1-2023-shell
This repo branch contains the shell for program 1 from cg class 2023 at nc state (ray tracing ellipsoids).

For this project, I implemented ray casting and Blinn-Phong illumination methodology and tested it on two still boxes to complete Part 1 and Part 2. The eye is located at (0.5, 0.5, -0.5), with a view up vector of [0 1 0] and a look at vector of [0 0 1].

For Part 3, I elaborated on this by creating a solution that randomly generates spherical objects of different radii within a boundary which are also illuminated by Blinn-Phong, to test how objects at different locations will be affected differently by the same lighting. This scene depicts yellow stars in the night sky.
